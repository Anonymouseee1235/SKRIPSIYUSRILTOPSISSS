## 📌 Deskripsi Proyek
Repository ini berisi file lengkap **Web Dashboard Interaktif** dan **Script Perhitungan MATLAB** untuk proyek skripsi:
**"Analisis Risiko Kegagalan Conveyor Pada Bagging Menggunakan FMEA Yang Terintegrasi Dengan Fuzzy AHP Dan Fuzzy TOPSIS Di PT. ABC"** oleh **Yusril Alfafa**.

---

## 📂 Struktur File Repository
- `index.html` : Halaman web dashboard utama (bisa dibuka langsung di browser).
- `style.css` : Styling tampilan dashboard bergaya Power BI Modern.
- `config.js` : Dataset & konfigurasi data skripsi.
- `script.js` : Script logika & pembuat grafik interaktif (Chart.js).
- `Code.gs` : Script Google Apps Script (opsional jika di-deploy via Google Apps Script).
- `assets/` : Folder tempat menyimpan file pendukung seperti `audio.mp3`.
- `matlab/` : Script perhitungan Fuzzy FMEA, Fuzzy AHP, dan Fuzzy TOPSIS.
- `data/` : Dataset CSV.

---

## 🚀 Cara Menjalankan
1. **Melihat Web Dashboard:**
   Cukup klik 2x file `index.html` untuk membuka dashboard langsung di browser tanpa perlu install software tambahan.
2. **Menambahkan Musik/Audio:**
   Masukkan file audio MP3 milikmu ke dalam folder `assets/` dengan nama `audio.mp3`.
